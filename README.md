# HealthMate AI 

HealthMate AI is a healthcare chatbot built using Python and Flask. It uses Google's Gemini AI to answer health-related questions and provide general health tips.

I built this project to learn Flask and explore how AI can be integrated into a web application.

### Features
- AI-powered healthcare chatbot
- Symptom checker
- General health tips
- Simple and user-friendly interface

### Technologies Used
- Python
- Flask
- Google Gemini AI
- HTML and CSS

### How to Run
1. Clone the repository.
2. Install the required dependencies.
3. Run `python app.py`.
4. Open the local URL in your browser.
5. Ask Questions.
6. Get Responses.

### Note
This project is for educational purposes only. The responses generated by the chatbot may not always be accurate and should not be considered professional medical advice. Please consult a qualified healthcare professional for medical concerns.
